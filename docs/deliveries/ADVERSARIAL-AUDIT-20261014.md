## 2. 当前发现与判定

### F1｜P1：全站官方原文无法跳转，根因未证实（#43）

证据文件：[cards.js](https://github.com/caor3693-cmyk/Workhunter-v2.0/blob/9ce46ceb926657a59616ac1741e498fd2e86820d/frontend/components/cards.js)、[dom.js](https://github.com/caor3693-cmyk/Workhunter-v2.0/blob/9ce46ceb926657a59616ac1741e498fd2e86820d/frontend/components/dom.js)、[test_cards.mjs](https://github.com/caor3693-cmyk/Workhunter-v2.0/blob/9ce46ceb926657a59616ac1741e498fd2e86820d/tests/test_cards.mjs)。

列表、详情、附件共用 `officialLink`，生成绝对 HTTP(S) anchor，`target='_blank'`、`rel='noopener noreferrer'`；DOM helper 设置属性，没有在此处拦截 click。**这只能排除这些已读函数中的明显禁用，不能证明部署页面点击正常，也不能证明 `_blank` 就是根因。**

现有卡片测试用自制 TextNode/假 DOM，断言 href、rel 和键盘可聚焦属性；没有执行真实浏览器导航。测试通过不足以覆盖用户“每条都是”的失败。此处是测试证据边界，不声称其他未读测试也全部缺失。

执行：先完成 #48 运行产物对账；在用户使用环境重现同一条公告，记录实际 href、点击接收、事件取消、导航/新页面、代理/构建身份和目标站限制。再与独立浏览器比较，定位是宿主导航、部署产物、事件链还是 URL 本身。只改已证实原因；有宿主限制时提供经过实际验证、可理解的外部打开/复制链接退路，不用伪装成功提示，不默认修改所有 URL 或降低安全规则。

验收：至少三校真实公告，列表与详情，鼠标与 Enter 均有可见导航且归属正确；在用户验收宿主验证，并与常规浏览器对照。访问受限与按钮失效分开记录；保留来源安全/内部详情/附件适用性回归。

### F2｜P2但首版必需：删首页区块不能只删 HTML（#42）

证据：[home.js](https://github.com/caor3693-cmyk/Workhunter-v2.0/blob/9ce46ceb926657a59616ac1741e498fd2e86820d/frontend/pages/home.js)。当前首页把 updates 放入 createPageReader；renderUpdates 无空值保护读取 `new-count`、`change-count`、`update-message`；render、reload 和 coordinateSidecars 仍引用 updates。只删除 DOM 会使后续渲染访问空节点；仅隐藏区块仍保留首页请求与协调依赖。这是拟实施方案的确定性风险，不是声称当前完整页面已崩溃。

执行：由同一前端整合者同步处理首页 DOM、import、reader、render、reload、sidecar 协调和首页读路由映射；不删除其他页面用到的公共摘要组件或后端统计。局部样式只收掉空白，不改整站首页骨架。

验收：网络面板/测试证明首页不再请求其专用 updates，首次加载、重载、学校校区、分页、近期/历史/未知视图仍可用；来源/维护页摘要继续工作。不能把“删除要求已通过”追溯写入 v5 历史结果。
