# Workhunter v2.0

面向电气与自动化应届求职者的十校招聘发现工具：按学校找到近期公告和活动，看清时间、举办地点、工作地点，并跳转官方原文。

本仓库承接独立重建。首版包括招聘发现、简要详情、站内更新摘要、受保护的维护网页和持续采集；独立岗位库、全国企业直采、完整参会名单工程后置。

## 开发入口

1. [产品规格](docs/PRODUCT.md)：已确认范围、八项产品决定、功能清单。
2. [数据与工程合同](docs/CONTRACTS.md)：字段证据、API、卡片和模块职责。
3. [执行任务](docs/TASKS.md)：工作包顺序、允许改动范围、验收与 Codex 指令。
4. [当前状态](docs/STATUS.md)：当前实际完成情况、发布状态及下一步。

项目排期与追踪见 [任务看板](docs/BOARD.md)、[一周路线图](docs/ROADMAP.md)，每阶段使用 [手工核验清单](docs/MANUAL_QA.md)。实际 Issue 和原生 Project 视图的完成状态统一登记在 STATUS；原生视图尚待 [配置任务 #19](https://github.com/caor3693-cmyk/Workhunter-v2.0/issues/19)。开发从 S0/W00 开始，先交付私有 Site，G0—G4 逐项验收后才正式上线。

开发者先读 [AGENTS.md](AGENTS.md)。规范版本为 1.1；八项产品范围保持不变，本次补充一周排期和阶段验收。产品名称中的 v2.0 与规范版本不是同一编号。

## 启动说明

首个实现工作包需要交付并实测安装、初始化独立数据库、启动页面、手动刷新、运行验证等命令，再在本节更新。不要从旧工程复制未在本仓库验证的启动命令。实现进度只维护在 `docs/STATUS.md`。

## 数据与公开材料

[十校入口种子](config/schools.json)用于启动官方来源核验。登记入口不代表自动采集可用、字段完整或覆盖完成。

源码仓库保存代码、公开配置、合同和少量经核验的脱敏测试样例。运行数据库、原始响应、备份、私有日志和凭据保留在各自运行环境。维护者可补充合法取得的官方公开材料，新业务库从近期官方来源重新采集。
